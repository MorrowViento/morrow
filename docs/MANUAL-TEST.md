# 真机验收清单 · 4.0.0-alpha1 (40)

> 本机无 adb 设备与模拟器，M2a–M6 的手工验收全部挂在这里。按 **P0 → P1 → P2** 顺序做，
> P0 不通过先别往下测（后面都建立在它上面）。每项都写了「预期」，不一致即为缺陷。

## 怎么反馈

一条缺陷请给到四项：**哪个模块 → 复现步骤 → 预期 → 实际（截图/录屏）**。
若是崩溃或异常退出，debug 包会把现场写到手机：

1. 打开「文件管理」→ 内部存储 → `Android/media/com.jiuxina.ying/`
2. 取 `startup.log`（启动轨迹）和 `crash-*.txt`（若有）

正式包不写这两个文件（诊断设施只在 debug 生效），所以复现请用 debug 包。

## P0 · 核心链路（不通过则不能发版）

### A. 启动与稳定性

- [ ] **A1 冷启动**：从桌面点图标进入。预期：正常显示首页，无一闪即退、无白屏残留
- [ ] **A2 冷启动 ×5**：连续杀进程（最近任务上滑清掉）再打开 5 次。预期：每次都能进，无偶发闪退
- [ ] **A3 后台回前台**：进首页 → 回桌面 → 点图标回来。预期：数据还在，无重建丢状态
- [ ] **A4 重启手机后首开**：重启 → 直接点图标。预期：正常进入，事件都在
  （这一项专门验证冷启动自愈链：迁移 / 撤销恢复 / 提醒对账 / 小部件刷新）
- [ ] **A5 断网冷启动**：开飞行模式 → 冷启动。预期：正常进入（应用不依赖网络）

### B. 新建 / 编辑（表单）

- [ ] **B1 点 + 号**：预期：弹出新建面板，**不闪退**（这是上一轮修过的坑，回归必测）
- [ ] **B2 最小输入**：只填标题 + 选日期 → 保存。预期：列表出现该事件，天数与日期一致
- [ ] **B3 全字段**：标题、日期时间、全天、方向（自动/倒数/正数）、每年重复、分类、提醒多条、备注 → 保存 → 重开编辑。预期：**每个字段都原样回填**
- [ ] **B4 提醒上限**：连续勾 6 条提醒。预期：第 6 条被拒并提示「最多 5 条提醒」，已选 5 条不丢
- [ ] **B5 标题为空**：不填标题点保存。预期：被拦下并提示，不产生空标题事件
- [ ] **B6 滚轮日期选择**：在表单里滚动年/月/日滚轮。预期：滚动顺滑，选中值与上方显示一致，**不卡死不闪退**
- [ ] **B7 过去日期**：目标日期设为 3 天前 → 保存。预期：进入「已过」状态，显示「已过去 3 天」
- [ ] **B8 编辑已存在事件**：改标题/日期 → 保存。预期：列表原地更新，不产生重复条目
- [ ] **B9 备注长文本**：备注粘贴 500 字以上。预期：能存能读，详情页可完整查看
- [ ] **B10 新建默认时刻**：在**非 9 点**的时间（例如 15:20）点 + 号。预期：滚轮默认停在**当前时刻**（15:20），日期为今天；保存后倒计时从此刻开始，不是今天 09:00

### C. 首页列表

- [ ] **C1 分区**：有进行中与已完成事件时。预期：两个分区标题与计数正确，已完成区可折叠/展开
- [ ] **C2 排序切换**：点排序胶囊循环「距离 → 日期 → 创建」。预期：三种顺序都符合直觉，重启后保持上次选择
- [ ] **C3 置顶**：详情页置顶 → 返回。预期：该事件排到进行中分区最前，取消置顶后归位
- [ ] **C4 完成/恢复**：详情页标记完成 → 返回。预期：移入已完成区并更新计数，恢复则反向
- [ ] **C5 空状态**：清空全部数据后。预期：显示「还没有倒数日」引导文案，不空白、不崩

### D. 删除与撤销（前台 6 秒窗口）

- [ ] **D1 单条删除**：详情页删除。预期：条目消失，底部出现撤销条
- [ ] **D2 6 秒内撤销**：立即点撤销。预期：事件完整恢复（含提醒与备注）
- [ ] **D3 超时不可撤销**：等 7 秒再看。预期：撤销条消失，事件不再恢复
- [ ] **D4 清空全部**：更多菜单 → 清空全部 → 确认。预期：二次确认弹窗文案正确，清空后可撤销
- [ ] **D5 撤销后重启**：删除 → 立即杀进程 → 重开。预期：撤销窗口仍有效（跨进程保留）
- [ ] **D6 切后台不烧窗口**：删除 → 立刻按 Home（或切到别的应用）→ 停留 10 秒以上 → 回到萤。预期：撤销条**仍在**，剩余秒数接着走（后台时间不计入 6 秒）；此时点撤销能完整恢复
- [ ] **D7 回前台后照常到期**：D6 回来后不再操作。预期：按剩余秒数正常消失，不会因为「冻结过」而永久停留
- [ ] **D8 划掉最近任务再重开**：删除 → 按 Home → 从最近任务上滑划掉萤 → 等 30 秒 → 点图标重开。预期：撤销条**重新出现并给满 6 秒**（不是残值），点撤销能恢复
- [ ] **D9 陈旧撤销不复活**：删除 → 划掉萤 → 超过 10 分钟再重开。预期：不显示撤销条

## P1 · 各模块功能

### E. 分类管理

- [ ] **E1 新增分类**：表单「管理分类…」→ 新建。预期：新分类立刻出现在表单选项里
- [ ] **E2 重命名**：改名后返回列表。预期：所有该分类的事件同步显示新名字
- [ ] **E2b 改名后表单跟进**：**先打开新建/编辑表单并选中某分类** → 进「管理分类…」把该分类改名 → 「完成」回到表单。预期：表单里选中项已是**新名字**、没有遗留旧名 chip；直接保存后，分类列表里只有新名字，不出现新旧两个分类
- [ ] **E3 删除被使用的分类**：删掉一个已有事件在用的分类。预期：弹「该分类下还有 N 个事件」并要求选一个迁移目标；选完这些事件改到目标分类，**一个都不丢**；不选则取消删除
- [ ] **E3b 删除后表单跟进**：表单选中某分类 → 管理页删掉它（有占用时选迁移目标）。预期：回到表单时选中项已改为迁移目标，保存不会把已删除的分类复活
- [ ] **E4 空名/重名**：留空或输入已存在的名字。预期：被拦下并提示

### F. 日历三视图

- [ ] **F1 打开日历**：首页入口进入。预期：**整页不透明，首页元素不透出**（上一轮修过的重叠问题，回归必测）
- [ ] **F2 月视图**：左右翻月、点某天。预期：日期下方有事件点的日子高亮，点日期下方出现当天事件列表
- [ ] **F3 年视图**：切「年」。预期：按月分组显示事件数，点月份可进到该月
- [ ] **F4 列表视图**：切「列表」。预期：按时间顺序铺开，分组标题正确
- [ ] **F5 回到今天**：翻到很远的月份 → 点「回到今天」。预期：跳回当月并选中今天
- [ ] **F6 关闭返回**：点 ✕。预期：回到首页，首页状态（滚动位置、分区展开态）保持
- [ ] **F7 日历内新建**：日历页点 + 号。预期：新建事件的日期默认 = 选中日（未选则为今天）
- [ ] **F8 农历与徽章**：查看某天。预期：农历显示正确（可与系统日历对照），「全天」「每年」标记正确

### G. 提醒（必须真机，JVM 测不到）

- [ ] **G1 发一条测试通知**：更多菜单 → 提醒 → 「发送测试通知」。预期：状态栏出现通知，点击能进应用
- [ ] **G2 真实到点提醒**：新建事件，目标时间设为 **2 分钟后**，加「事件发生时」提醒 → 等待。
  预期：准点弹出通知（误差应在几秒内），标题含事件名，文案含剩余天数
- [ ] **G3 提前提醒**：目标时间设为 1 小时后，加「提前 30 分钟」→ 预期在 30 分钟后触发，**不晚于 30 秒**
- [ ] **G4 点通知进详情**：点通知。预期：直接打开该事件的详情页，不是首页
- [ ] **G5 通知权限关闭**：系统设置里关掉通知权限 → 回到应用的提醒页。预期：显示「未开启」并能一键跳系统设置
- [ ] **G6 精确闹钟权限**：进提醒页。预期：显示「精确闹钟 · 已允许」（`USE_EXACT_ALARM` 安装即授予，正常应已允许）；
  若为「未允许」，说明该 ROM 不认这条权限，需手动点「去开启」，且排期会延迟、页面会给出提示
- [ ] **G6b 延迟观测**：触发过至少一次提醒后再进提醒页。预期：排期标题下方出现一行
  「上次提醒准时」；若显示「晚了几分钟，系统在推迟闹钟」，说明系统仍在拖（多半是省电策略，需把应用设为「不受限制」）。
  若括号里出现「应用处理耗时 N 秒」，那是应用自身的问题，需要我继续查
- [ ] **G6c 后台运行未被限制**：提醒页「后台运行」一行。预期显示「不受电池限制」；
  若显示「系统可能冻结后台」，点「去设置」把「萤」设为「不受限制」，再重测 G3
- [ ] **G7 重启后闹钟仍在**：设一个 10 分钟后的提醒 → 重启手机 → 等待。预期：**仍准时触发**（开机重排生效）
- [ ] **G8 改系统时间**：设提醒 → 把系统时间前移 1 天 → 回应用。预期：过期提醒不再误报，排期列表刷新正确
- [ ] **G9 已过事件不提醒**：目标时间在过去的事件。预期：排期列表里不出现，不会触发
- [ ] **G10 每年重复事件**：去年已过、今年未到的每年重复事件。预期：按今年日期排期，不是按去年

### H. 桌面小部件（必须真机）

- [ ] **H1 添加总览小部件**：长按桌面 → 小部件 → 添加。预期：立即显示事件列表，不是空白/「加载中」
- [ ] **H2 配置台**：添加时进入配置页。预期：有实时预览；切 1/3/5 行预设、三档字号、四套配色、三个开关都即时反映在预览上
- [ ] **H3 保存后生效**：配置完保存。预期：桌面小部件按所选样式渲染，字号与配色正确
- [ ] **H4 长按改尺寸**：把 1 行小部件拉成 5 格高。预期：行数随高度合理变化，无文字截断或溢出
- [ ] **H5 重新配置**：长按小部件 → 编辑/重新配置。预期：打开配置页且带上当前样式（不是回到默认）
- [ ] **H6 数据联动**：应用内新建/完成/删除一个事件。预期：**几秒内**小部件自动刷新，无需手动
- [ ] **H7 单事件小部件**：添加单事件版本并绑定某事件。预期：只显示该事件，徽章与进度正确
- [ ] **H8 跨零点刷新**：晚上添加小部件，第二天早上看。预期：天数已 +1（无需打开应用）
- [ ] **H9 重启后小部件**：重启手机。预期：小部件仍显示正确内容，不显示旧数据或「加载失败」
- [ ] **H10 深色模式联动**：配色选「跟随系统」→ 切换系统深色模式。预期：小部件背景与文字颜色一起切换
- [ ] **H11 删除小部件**：从桌面移除。预期：无残留闹钟（可在提醒页确认排期未异常）

### I. 设置中心

- [ ] **I1 进入设置**：更多菜单 → 设置。预期：整页覆盖、玻璃背景完整，**首页元素不透出**
- [ ] **I2 主题三态**：跟随系统 / 浅色 / 深色 逐个切换。预期：底色与文字**一起**变（不能出现浅底深字或深底深字）
- [ ] **I3 减弱透明**：开启。预期：玻璃降级为不透明面板，内容变清晰；关闭后恢复玻璃
- [ ] **I4 减弱动效**：开启后切换页面。预期：无淡入淡出，即时切换
- [ ] **I5 主题持久化**：设成深色 → 杀进程 → 重开。预期：仍是深色
- [ ] **I6 返回**：按返回键或关闭。预期：回到首页且首页状态保持

### J. 备份导入导出（必须真机，涉及 SAF）

- [ ] **J1 导出到本地**：数据 → 导出备份 → 选「下载」目录。预期：生成 `.json` 文件，用文件管理器能看到
- [ ] **J2 检查内容**：用文本编辑器打开。预期：可读的 JSON，含事件、分类、外观、小部件样式
- [ ] **J3 导出到云盘**：选网盘（如微信/OneDrive）。预期：能正常写入不报错
- [ ] **J4 覆盖导入**：改几条数据 → 导入 → 选「覆盖」。预期：本机数据被备份完整替换，导入后有成功汇总提示
- [ ] **J5 合并导入**：导入同一份 → 选「合并」。预期：同 id 事件被备份覆盖、本机独有事件保留，**外观与小部件样式不变**
- [ ] **J6 重复导出覆盖同名文件**：导出两次到同一路径。预期：第二次正常覆盖（不残留旧内容尾部）
- [ ] **J7 坏文件**：导入一个文本文件或空文件。预期：给出可读错误提示，**不清空本机数据**
- [ ] **J8 导入后提醒对账**：导入带提醒的事件 → 看提醒页排期。预期：排期数量与事件提醒数一致
- [ ] **J9 导入后小部件**：导入后看桌面小部件。预期：内容随之更新
- [ ] **J10 清除全部数据**：执行。预期：二次确认 → 清空后事件、分类、小部件样式、设置均回初始；提醒排期清空
- [ ] **J11 清空后小部件**：清空数据后看桌面。预期：小部件显示空状态而非旧数据

## P2 · 边界与兼容

### K. 旧数据迁移（仅当从 Flutter 版升级时）

- [ ] **K1**：手机上保留 Flutter 版「萤」的旧数据 → 装本包 → 打开。预期：旧事件、分类、排序偏好被迁过来
- [ ] **K2 幂等**：迁移完成后再杀进程重开。预期：不重复导入、不产生重复事件
- [ ] **K3 首装无旧数据**：全新机器。预期：直接空状态，无迁移报错

### L. 边界输入

- [ ] **L1 超长标题**：粘贴 100 字标题。预期：列表与详情不溢出、不重叠，必要时省略号
- [ ] **L2 极端日期**：目标日期设到 2099 年 / 2000 年。预期：天数计算正确，不溢出
- [ ] **L3 同秒多次点击保存**：快速连点保存 3 次。预期：只产生 1 条事件
- [ ] **L4 提醒全勾**：5 条提醒全选最长档位（提前 1 周等）。预期：排期正确计算，不崩

### M. 系统级兼容（Android 16 上重点看）

- [ ] **M1 深色模式**：系统切深色/浅色，主题设为「跟随系统」。预期：全局跟着变，无残留
- [ ] **M2 大字体**：系统字体调到最大。预期：文字不重叠、不截断，布局可读
- [ ] **M3 屏幕旋转**：转横屏。预期：不崩，布局合理（或锁定竖屏）
- [ ] **M4 分屏/小窗**：分屏打开。预期：不崩，内容自适应
- [ ] **M5 手势返回**：从屏幕边缘返回。预期：各页面（日历/设置/详情）都能正确退出
- [ ] **M6 权限拒绝后不再询问**：拒绝通知权限两次 → 再次点「开启」。预期：跳到系统设置页，不纠缠
- [ ] **M7 低电耗模式**：开省电模式 → 等到点提醒。预期：提醒仍触发（可能略延迟，属正常）

## 测试顺序建议

1. **先 20 分钟走 P0**（A → B → C → D）：这段不过，后面都没有意义
2. **再 30 分钟走 P1 的 G/H**（提醒与小部件）：这两块此前完全没上过真机，风险最高
3. **最后过 I/J**（设置与备份）：涉及 SAF 与多文件路径，问题多为"某些目录写不进"
4. **P2 有空再扫**，其中 K（迁移）只有从旧版升级才需要

发现问题直接告诉我编号（如 `G7 重启后提醒没响`）+ 截图，我按编号定位。
